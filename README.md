# F1 Stats

Aplicación web de estadísticas de Fórmula 1 construida con React, TypeScript y Tailwind CSS.

## Características

- Listado de temporadas desde 1997 hasta 2026
- Perfiles detallados de pilotos
- Información de equipos y constructores
- Circuitos con récords y estadísticas
- Resultados de carreras en tiempo real
- Estadísticas globales
- Diseño responsive
- Búsqueda y filtros

## Tecnologías

- React 18
- TypeScript
- Tailwind CSS
- React Router v6
- TanStack Query
- Tabler Icons
- Vite
- GitHub Pages

## Instalación

```bash
# Clonar repositorio
git clone https://github.com/tu-usuario/f1-stats.git
cd f1-stats

# Instalar dependencias
npm install

# Configurar variables de entorno
cp .env.example .env
# Editar .env con tu clave de API

# Iniciar en desarrollo
npm run dev
